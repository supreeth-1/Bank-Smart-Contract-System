Getting started

Try this classroom demo:

1. Select Alex · Bank Admin and fund the lending pool.
2. Select Asha and deposit ETH.
3. Transfer to Ravi or withdraw.
4. Request a loan, then repay it.

To use a real smart contract:

1. Deploy SimpleBank.sol through Remix using MetaMask on Sepolia.
2. Paste the deployed contract address below.
3. Connect MetaMask, approve customers as admin, then transact with Sepolia test ETH.

Use Remix to deploy and a Sepolia faucet to get test ETH. Transactions require network gas.
